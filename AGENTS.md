# Repository update convention

- For every user-visible update, update the main `README.md` before finishing.
- Place a block immediately below the top-level title:
  `> **最新更新 / Latest update · YYYY-MM-DD**`
- State what changed, the user-facing entry point, and any important boundary in one or two lines.
- Keep older update details in changelog or version files, not stacked indefinitely at the top of README.
- This convention applies to documentation, product, teaching and whitepaper changes alike.
